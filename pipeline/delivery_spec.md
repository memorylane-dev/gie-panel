# 집계 사양서 — v2

2026-09-24 연구자 답변을 반영한 재집계 기준입니다. 입력 파일은 정제된 `micro_*.csv` 8개와
지표 정의 `dim_indicator.csv`입니다. 학교급은 중학교이고 별도 조사 가중치는 없습니다.

## 1. 표시와 집계 단위

`화면표시=숨김`은 화면에서 제외합니다. `단년도`는 해당 연도만 표시하며 비교선·증감·헤드라인을
만들지 않습니다. 교사 디지털 활용 역량 4개는 2025년 단년도 지표입니다.
숨김 지표도 처리 이력 보존을 위해 마이크로데이터와 지표별 집계 파일에는 남아 있습니다.
원점수 역량 총점 3개는 전달본에서 제외하고 환산점수 3개만 제공합니다.

개인 자료는 응답자·지표·주기당 한 행, 학교 자료는 학교·지표·주기당 한 행입니다.
주기 간 개인 ID 연결은 성립하지 않습니다. 학교 설문에서는 `응답자ID=학교ID`입니다.

| 산출물 | 그룹 기준 |
|---|---|
| 지표 전체 집계 | indicator_id + 조사연도 |
| 지표 지역 집계 | indicator_id + 조사연도 + 지역규모코드 |
| 문항 분포 | indicator_id + 조사연도 + 값 |
| 소주제 평균 | 소주제코드 + 응답주체 + 조사연도 |

`fact_indicator_wave`에는 전체(지역규모코드 0)와 지역(1·2) 행이 공존합니다.
`fact_indicator_wave_region`은 그중 지역 행만 담은 분리본입니다.

## 2. 정제된 값의 의미

- `값`은 코드 범위 검증, 지정된 다중응답 공란 보정, 음수 금액·횟수 결측 처리를 거친 원척도 응답입니다.
- 역문항도 `값`과 문항별 분포·대표값은 원척도를 유지합니다. 역채점은 구인 평균 계산에만 적용합니다.
- 학교 중복 응답은 문항별 유효 비결측값이 하나로 일치하면 통합하고, 서로 다르면 결측 처리합니다.
  정수인 0 이상의 횟수만 유효합니다. `결측보정`에 통합·충돌 처리 이력이 있습니다.
- 학생 문화활동은 시계열에서 제외했으므로 과거의 사교육 참여자 한정 보정도 적용하지 않습니다.
- 역량은 SPSS에 있는 기존 환산점수(0점부터 100점까지)를 사용하며 결측값은 대체하지 않습니다.

## 3. 공통 통계

그룹의 비결측 `값`을 v로 두고 응답수=count(v), 결측수=전체 행 수-count(v)로 계산합니다.
평균과 표본표준편차(ddof=1)는 소수 4자리, 중앙값과 25·75백분위는 원 정밀도를 유지합니다.
표준편차는 유효값이 1개 이하면 공란입니다. 유효값이 없으면 모든 수치 통계는 공란입니다.
학교 지표의 응답수·결측수 단위는 학교 수입니다.

## 4. 유형별 통계와 대표값

| 통계유형 | 대표값 | 단위 |
|---|---|---|
| likert | (원평균−척도최소)/(척도최대−척도최소)×100, 소수 2자리 | 환산100점 |
| binary | 긍정코드 응답 수 / 유효 응답 수 × 100, 소수 2자리 | % |
| continuous | 0 초과 지출자의 중앙값, 없으면 유효값 전체 중앙값 | 만원 |
| score100 | 기존 역량 환산점수의 평균, 소수 2자리 | 점 |
| school_rate | 동일 학교 집합의 발생 건수 합계 / 학생 수 합계 × 100, 소수 4자리 | 학생 100명당 발생 건수 |
| school_count | 학교별 실시 횟수의 평균, 소수 4자리 | 학교당 횟수 |
| excluded | 공란 | 해당없음 |

### 선택형과 역채점

`환산100`은 원평균을 환산한 값입니다. `구인환산100`은 소주제 평균에 사용할 점수입니다.
역문항(`역문항=Y`)은 원평균을 `척도최소+척도최대−원평균`으로 바꾼 뒤 환산합니다.
즉 반올림 전 환산점수를 100에서 빼고 마지막에 소수 2자리로 반올림합니다.
다른 선택형 문항은 `구인환산100=환산100`입니다.
`상위2선지비율`은 원척도의 상위 두 코드 비율이며 역채점하지 않습니다.

### 금액형

지출자수=count(v>0), 지출참여율=지출자수/전체 행 수×100(소수 2자리)입니다.
지출자평균은 소수 4자리이며, 유효값 20개 이상일 때 1·99백분위 범위 안의 값으로 절사평균을 계산합니다.
2주기 공란의 의미는 확인 중입니다. 지출참여율은 공란=미지출 가정이 필요하며,
전체 평균의 주기 간 직접 비교는 하지 않습니다. 지출자 기준 통계를 사용합니다.
역량·학교 지표에는 지출자 통계를 적용하지 않습니다.

### 학교폭력 분모

`분모학생수`는 같은 조사주기 학교DB의 1·2·3학년 남녀 학생 수 6개를 합산한 값입니다.
6개 값이 모두 유효하고 합계가 0보다 커야 합니다. 발생 건수와 분모가 모두 유효한 학교만
분자·분모에 함께 포함합니다. 한쪽만 합산하지 않습니다.

- `발생건수합계`: 위 학교들의 발생 건수 합계
- `분모학생수합계`: 같은 학교들의 학생 수 합계
- `발생률산출학교수`: 같은 학교들의 수

학교별 발생률의 단순 평균이 아닙니다. 0건 학교도 포함합니다. 모든 분모가 결측인 그룹은
대표값을 공란으로 둡니다. 현재 자료는 학생 수를 연결할 수 있어 학교당 건수 평균으로의 대체를 사용하지 않습니다.
피해 학생 비율로 해석하지 않으며, 주기별 응답 학교 구성과 학생 수 기준을 주의사항으로 표시합니다.

## 5. 분포와 소주제 평균

분포는 likert·binary의 원척도 `값`으로 계산합니다. 코드별 비율의 분모는 지표·연도별 유효 N입니다.
선지 라벨은 indicator_id + 조사연도 + 코드로 결합합니다. 숨김 지표의 분포는 화면에서 제외합니다.

소주제 평균에는 `소주제평균포함=Y`인 지표의 **지역규모코드=0인 전체 집계만** 사용합니다.
각 지표의 `구인환산100`을 동일 가중으로 평균내고 소수 2자리로 반올림합니다.
`평균응답수`는 문항별 N의 평균을 정수 반올림한 값이며 고유 인원수가 아닙니다.
학교 지표·역량 3개는 각각의 의미와 단위가 달라 이 선택형 소주제 평균으로 합치지 않습니다.

역문항 `ST_RELATION_06`, `PR_RELATION_02`, `PR_RELATION_05`는 역채점 후 포함합니다.
`ST_RELATION_02`는 구인 평균에서 제외하고 그 사실을 표시합니다. 문항 단독 정보는 원척도로 유지합니다.
교사 디지털 활용 역량은 단년도 소주제 평균만 계산합니다.

## 6. 헤드라인 후보

시계열 비교 가능한 소주제 중 최신 두 주기에 모두 값이 있는 경우만 후보를 만듭니다.
증감=최신값−직전값, 증감률=증감/직전값×100이며 소수 2자리로 반올림합니다.
직전값이 0이면 증감률은 공란입니다. 절대증감의 내림차순 min 순위를 사용합니다.
`선정상태=후보(선정 미확정)`이며 최종 화면 노출 목록은 아직 결정되지 않았습니다.

값의 결측 여부가 다르거나 행이 빠진 경우도 실패합니다.
