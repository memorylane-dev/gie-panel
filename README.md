# gie-panel

경기교육데이터 시각화 서비스 유지·관리 용역 중
**[메뉴2-2] 교육데이터 시각화 – 패널 데이터** (과업지시서 SFR-001) 구축을 위한
경기학교교육실태조사 시계열 데이터 정제 저장소.

원본 SPSS 자료를 시각화 업체가 대시보드에 바로 바인딩할 수 있는 형태로 정제하고,
1주기(2021)–2주기(2025) 변수 매핑에 근거한 지표 체계를 산출합니다.

> ⚠️ 개인 단위 조사 원자료를 포함합니다. **비공개 저장소로만 운영**하며 외부 공유 시
> `delivery/` 산출물만 전달합니다.

### 재현

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python pandas pyreadstat openpyxl
.venv/bin/python pipeline/build.py
```

스크립트는 저장소 루트를 자동 인식하므로 어느 경로에서 실행해도 동일한 결과를 생성합니다.

### SPSS 원자료 열람 (SPSS 프로그램 불필요)

```bash
.venv/bin/python tools/sav_export.py
```

`data/exports/` 에 10개 파일이 두 벌로 생성됩니다.

| 구분 | 내용 | 용도 |
|---|---|---|
| `라벨적용/` | 선지가 텍스트로 치환 (`1` → `남성`) | 눈으로 확인, 보고서 인용 |
| `코드값/` | 원 숫자 코드 유지 | 재분석, 통계 처리 |
| `코드북_전체.xlsx` | 파일별 시트에 변수명·설명·척도·선지·응답수·결측수·기초통계 | 변수 탐색 |

CSV는 UTF-8 BOM이라 엑셀에서 바로 열립니다. ID·코드 열은 정수로 출력되어
`1001.0` 같은 부동소수 표기가 생기지 않으며, 역량 환산점수 등 연속형은 원값을 유지합니다.

### 신규 주기 추가

1. `data/raw/wave3_YYYY/` 에 SPSS 원본 배치
2. 변수매칭 시트에 3주기 변수명 컬럼 추가
3. `build.py`의 `WAVES` · `SRC`에 3주기 항목 추가
4. 재실행 — 집계·헤드라인·분포표가 자동 확장됨 (매핑 구조 변경 불필요)

## 적용한 정제 규칙

| 규칙 | 내용 |
|---|---|
| R1 | 다중응답 이분문항의 미선택 결측 → `0` 보정 (1주기 학부모 `Q8_2_1~7`) |
| R2 | 코드북 선지 정의 범위를 벗어난 값 결측 처리 |
| R3 | 연속형 음수 결측 처리 + 상하위 1% 절사평균 병기 |
| R4 | 역문항 자동 역채점 없이 표시만, 소주제 평균에서 제외 |
| R5 | 연계판정 ③·④ 및 코딩 이상 지표는 시계열에서 제외 |
| R6 | 지역규모는 각 주기 학교DB(`YM1_DB0_3`/`YM2_DB0_3`)를 `SCHID`로 결합 |

4·5·6점 척도가 혼재하므로 전 지표에 **환산100**(`(평균−최소)/(최대−최소)×100`)을 부여해
소주제·대분류를 가로지르는 비교의 공통 축으로 사용합니다.

## 검증

- 변수매칭 223행 전부가 실제 SPSS 변수와 1:1 존재 — 미존재 0건, 선지수 불일치 0건
- 리커트 지표 무작위 12개 × 2주기를 원본에서 독립 재계산 대조 — 불일치 0건
- 선지 분포표 비율합·지역규모 교차 집계 — 이상 0건
- 폴더 재구성 후 재실행 산출물 해시 동일 — 재현성 확인

## 확인 필요 사항

1. **2주기 학부모 `PRQ3_2_5`·`PRQ3_2_6`에 `1` 코드 부재** — 결측이 '해당'일 가능성, 연구원 확인 요청
2. **헤드라인 1위 `진로·진학 준비`(+20.7%)** — 조건부 응답 기저 및 문항명 변경, 대표 지표 배치 전 검토 권장
3. **대분류 체계** — `<표 4>` 원안 조정(C05 공란, C10~C12 추가)에 대한 연구원 승인 필요
