# 집계 사양서

관리자 화면에서 개인 단위 원자료(``)를 업로드하면 시스템이 집계하는
방식을 전제로, 그 집계 절차를 규정한 문서입니다.

**이 문서만으로 재구현이 가능하도록 작성했습니다.** 구현 후에는 8장의 검증 절차로
기존 산출물(`fact_*` 파일)과 대조해 주십시오. 일치하면 구현이 정확한 것입니다.

---

## 0. 식별자에 관하여

집계에는 `응답자ID`·`학교ID`가 **사용되지 않습니다**(2장 참조). 그룹 기준으로 쓰지 마십시오.

| 컬럼 | 구조 | 유의 |
|---|---|---|
| `학교ID` | 4자리. 주기 간 동일 학교를 가리킴 | 학교 단위 추적 가능 |
| `응답자ID` | `학교ID × 10000 + 학교 내 순번` | **주기 간 동일인이 아님** |

`응답자ID`는 개인 식별자가 아니라 학교 내 일련번호이며 주기마다 새로 부여됩니다.
2021년 중학생은 2025년에 고등학생이므로 동일인의 재응답은 성립할 수 없습니다.
**시점 간 개인 연결을 시도하지 마십시오.**
단, 학부모의 `응답자ID`는 자녀의 학생 ID이므로 **동일 주기 내에서는** 학생–학부모 결합이 가능합니다.

## 1. 입력

| 파일 | 역할 |
|---|---|
| `micro_*_{연도}.csv` | 개인 단위 응답. `값` 컬럼은 **이미 정제가 완료된 상태**입니다. 응답주체·주기별 6개 파일이며 모두 이어붙여 사용합니다 |
| `dim_indicator.csv` | 집계에 필요한 모든 파라미터(척도 범위·통계유형·긍정코드·역문항 등) |
| `dim_school.csv` | 지역규모 결합용 (마이크로데이터에 이미 결합되어 있음) |

마이크로데이터에는 파생 가능한 컬럼을 두지 않았습니다. 필요 시 아래에서 조회하십시오.

| 필요한 값 | 조회처 | 키 |
|---|---|---|
| 조사명 · 학교급 · 주기명 | `dim_wave` | `조사연도` |
| 지역규모 명칭 | `dim_region` | `지역규모코드` |
| 원변수명(SPSS) · 문항명 | `dim_indicator` | `indicator_id` |

> **중요** — 마이크로데이터의 `값`에는 결측 보정·범위 검증·기저 정렬이 모두 적용되어 있습니다.
> 별도 전처리 없이 그대로 집계하십시오. 적용된 보정은 `결측보정` 컬럼에 표기됩니다.

## 2. 집계 단위

`값`이 비어 있지 않은 행만 대상으로 합니다.

| 산출 테이블 | 그룹 기준 |
|---|---|
| `fact_indicator_wave` (지역규모='전체') | `indicator_id` + `조사연도` |
| `fact_indicator_wave` (지역규모≠'전체') | `indicator_id` + `조사연도` + `지역규모코드` |
| `fact_indicator_dist` | `indicator_id` + `조사연도` + `값` |

전체 행과 지역별 행을 **하나의 테이블에 함께** 담습니다. 전체는 `지역규모코드=0`,
`지역규모='전체'`로 표기합니다.

## 3. 기본 통계량

각 그룹에 대해 아래를 산출합니다. `v`는 그룹 내 `값`의 집합(결측 제외)입니다.

| 컬럼 | 산식 |
|---|---|
| `응답수` | `count(v)` |
| `결측수` | 그룹 내 전체 행 수 − `응답수` |
| `평균` | `mean(v)`, 소수 4자리 반올림 |
| `표준편차` | 표본표준편차(n−1), 소수 4자리. 응답수 1이면 공란 |
| `중앙값` | `median(v)` |
| `백분위25` | `quantile(v, 0.25)` |
| `백분위75` | `quantile(v, 0.75)` |

## 4. 지표 유형별 추가 통계량

`dim_indicator.통계유형`으로 분기합니다.

### 4-1. `likert` (선택형)

`dim_indicator`의 `척도최소`·`척도최대`를 사용합니다.

```
환산100      = (평균 − 척도최소) ÷ (척도최대 − 척도최소) × 100      … 소수 2자리
상위2선지비율 = v 중 값이 척도최대 또는 (척도최대−1) 인 비율 × 100   … 소수 2자리
```

> 척도가 4점·5점·6점으로 혼재하므로 **원 평균으로는 지표 간 비교가 성립하지 않습니다.**
> 그래프에는 반드시 `환산100`(또는 5장의 `대표값`)을 사용하십시오.

### 4-2. `binary` (이분형)

`dim_indicator.긍정코드`를 사용합니다.

```
긍정응답률 = v 중 값이 긍정코드와 같은 비율 × 100                   … 소수 2자리
```

긍정코드는 지표마다 다릅니다(`0` 또는 `1`). 반드시 `dim_indicator`에서 읽으십시오.

### 4-3. `continuous` (금액형)

```
지출자수     = count(v > 0)
지출참여율   = 지출자수 ÷ (그룹 내 전체 행 수) × 100                … 소수 2자리
지출자평균   = mean(v > 0), 소수 4자리
지출자중앙값 = median(v > 0)
절사평균     = 상·하위 1% 절사 후 mean. 응답수 20 미만이면 공란
```

> `지출참여율`의 분모는 **결측을 포함한 전체 행 수**입니다(`응답수`가 아님).

## 5. 대표값

지표 유형과 무관하게 그래프 y축에 바로 쓰는 단일 값입니다.

| 통계유형 | `대표값` | `대표값유형` |
|---|---|---|
| `likert` | `환산100` | `환산100점` |
| `binary` | `긍정응답률` | `긍정응답률(%)` |
| `continuous` | `지출자중앙값` (없으면 `중앙값`) | `지출자 중앙값(만원)` |
| 그 외 | 공란 | 공란 |

## 6. 선지 분포 (`fact_indicator_dist`)

`통계유형`이 `likert` 또는 `binary`인 지표만 대상입니다.

```
응답수 = 해당 (indicator_id, 조사연도, 값) 조합의 건수
비율   = 응답수 ÷ (같은 indicator_id·조사연도의 응답수 합계) × 100   … 소수 2자리
선지라벨 = dim_value_label 에서 (indicator_id, 조사연도, 코드) 로 조회
```

> 같은 코드라도 **주기별로 라벨 표현이 다를 수 있습니다.**
> 예: 코드 `1`이 1주기 "전혀 만족하지 않음", 2주기 "매우 불만족".
> 반드시 조사연도를 포함해 조회하십시오.

## 7. 소주제 집계와 헤드라인

### 7-1. `fact_topic_wave`

아래 조건을 **모두** 만족하는 지표만 포함합니다.

1. `통계유형` = `likert`
2. `시계열비교가능` ∈ {`Y`, `조건부`}
3. `역문항` = `N` — **`Y`(역문항)와 `척도 부적합`은 제외합니다**

```
그룹     = 대분류코드 + 소주제코드 + 응답주체 + 조사연도
지표수   = 그룹 내 고유 indicator_id 수
평균환산100 = 그룹 내 지표들의 환산100 평균                          … 소수 2자리
평균응답수  = 그룹 내 지표들의 응답수 평균, 정수 반올림
```

> 3번 조건이 중요합니다. 역문항은 다른 문항과 방향이 반대여서 그대로 평균에 넣으면
> 서로 상쇄됩니다. `dim_indicator.역문항` 값이 `N`이 아닌 지표는 반드시 제외하십시오.

### 7-2. `fact_headline`

`fact_topic_wave`에서 **가장 최근 두 시점**을 비교합니다.
(현재는 2021·2025이나, 주기가 추가되면 최신 두 개를 사용하도록 구현하십시오.)

```
증감         = 최신 시점 평균환산100 − 직전 시점 평균환산100          … 소수 2자리
증감률       = 증감 ÷ 직전 시점 값 × 100                             … 소수 2자리
변화방향     = 증감 > 0 이면 '증가', < 0 이면 '감소', 0이면 '유지'
절대증감순위 = |증감| 내림차순 순위. 동점은 같은 순위(min 방식)
```

두 시점 중 하나라도 값이 없는 소주제는 제외합니다.

## 8. 검증 절차

구현 후 아래를 확인하십시오. 현재 제공된 `fact_*` 파일 파일이 정답에 해당합니다.

| 검증 | 기준 |
|---|---|
| 1 | `fact_indicator_wave`의 행 수가 1,371인가 (지표 457 × 전체·중소도시·읍면지역) |
| 2 | `응답수`가 제공 파일과 **완전히 일치**하는가 |
| 3 | `환산100`의 최대 오차가 0.01 이하인가 |
| 4 | `fact_indicator_dist`의 `비율` 합이 지표·연도별로 100 ± 0.05 인가 |
| 5 | `fact_topic_wave`의 소주제 수가 32인가 (역문항 제외가 반영되었는지 확인) |
| 6 | `fact_headline`의 행 수가 41인가 |

**표본 확인용 값** — 학생 전반적 만족도(`ST_SAT_TOTAL_01`), 지역규모 '전체'

| 조사연도 | 응답수 | 평균 | 환산100 | 상위2선지비율 |
|---|---|---|---|---|
| 2021 | 8,884 | 3.5589 | 63.97 | 55.25 |
| 2025 | 5,173 | 3.5482 | 63.71 | 54.67 |

## 9. 참조 구현

동봉된 **`05_집계검증.py`** 가 위 사양의 참조 구현입니다.
3~7장의 절차를 그대로 구현하고 8장의 검증까지 수행합니다.

```bash
pip install pandas
python 05_집계검증.py
```

이 패키지 안의 파일만으로 실행되며, 마이크로데이터를 읽어 집계한 뒤
`fact_*.csv` 와 대조한 결과를 출력합니다. 로직이 모호한 부분은 코드를 확인하십시오.

## 10. 주기 추가 시

1. 새 주기 데이터를 마이크로데이터와 동일한 스키마로 적재합니다
   (`조사연도 · 응답주체 · 응답자ID · 학교ID · indicator_id · 값 · 결측보정 · 지역규모코드`).
2. `dim_wave`에 행을 추가합니다.
3. `dim_indicator`에 새 주기의 원변수명 컬럼을 추가합니다.
4. 재집계하면 모든 화면이 자동 확장됩니다. 매핑 구조 변경은 불필요합니다.

> 개인 단위 응답자는 주기 간 연결되지 않습니다(반복 횡단 설계).
> `응답자ID`로 시점 간 조인을 시도하지 마십시오. 상세는 `docs/ID구조와매칭.md` 참조.
