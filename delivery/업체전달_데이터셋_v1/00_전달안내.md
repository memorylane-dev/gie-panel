# 전달 안내

경기교육데이터 시각화 서비스 유지·관리 용역 `[메뉴2-2] 교육데이터 시각화 – 패널 데이터`
(과업지시서 SFR-001) 구축용 데이터입니다.

## 파일 구성

번호가 붙은 문서 4개를 순서대로 읽으신 뒤, 접두어로 구분된 데이터 파일을 사용하시면 됩니다.

| 파일 | 내용 |
|---|---|
| `00_전달안내.md` | 이 문서 |
| `01_데이터정의서.md` | 화면 영역별 파일 대응, 정제 규칙, 확인 필요 사항 |
| `02_테이블정의서.xlsx` | 테이블 목록·컬럼 정의·테이블 관계·명명 규칙 |
| `03_집계사양서.md` | **집계 절차 규정.** 관리자 화면에서 원자료를 재집계하므로 필수 |
| `04_변수매핑정의서.xlsx` | 1·2주기 문항 대응 내역 (참고용) |
| `05_집계검증.py` | 집계 참조 구현 겸 검증 도구. 실행하면 구현 정확성을 대조합니다 |

### 데이터 파일의 접두어

파일명 앞부분이 그 파일의 성격을 나타냅니다.

| 접두어 | 뜻 | 개수 | 성격 |
|---|---|---|---|
| **`dim_`** | dimension, **차원** | 8 | 변하지 않는 정의·분류·코드표. 지표가 *무엇인지* 설명합니다 |
| **`fact_`** | fact, **사실** | 5 | 측정된 수치. 지표의 *값이 얼마인지* 담습니다. 시점이 늘면 행이 늘어납니다 |
| **`micro_`** | microdata, **원자료** | 6 | 개인 단위 응답. 집계의 원본이며 관리자 화면 갱신 시 업로드합니다 |

`dim_`과 `fact_`는 BI 도구에서 널리 쓰는 구분입니다.
예를 들어 `dim_indicator`는 "전반적 만족도라는 지표가 5점 척도이고 만족도 대분류에 속한다"를
한 줄로 기록하고, `fact_indicator_wave`는 "그 지표가 2021년에 63.97, 2025년에 63.71이었다"를
시점마다 한 줄씩 기록합니다.

화면을 그릴 때는 주로 `fact_`를 쓰고, 탭 이름·선지 라벨처럼 표시할 문구는 `dim_`에서 가져옵니다.

## 구축 시 핵심 사항 3가지

**① 그래프에는 `대표값` 컬럼을 사용하십시오.**
지표마다 적절한 통계량이 다릅니다(선택형=환산100점, 이분형=긍정응답률, 금액형=지출자 중앙값).
`대표값`에 이미 계산되어 있으므로 지표 유형별 분기가 필요 없습니다.
**원 `평균` 컬럼으로 그래프를 그리면 4·5·6점 척도가 혼재하여 지표 간 비교가 성립하지 않습니다.**

**② 대분류·소주제 탭은 `dim_category` / `dim_topic`을 읽어 구성하십시오.**
분류 체계가 확정 전이므로 탭 목록이 변경될 수 있습니다.
파일을 읽어 그리도록 구현하면 데이터 교체만으로 반영됩니다.

**③ 다계열 그래프는 `dim_cross_respondent`를 확인하십시오.**
복수 응답주체를 한 화면에 표시하는 조합 27개 중 **12개만 성립**합니다.
나머지 15개는 한쪽 주체의 문항이 조사에서 선택되지 않아 단일 계열로 표시해야 합니다.

## 파일 형식

모든 파일은 **압축하지 않은 CSV(UTF-8 BOM)** 입니다. 별도 도구 없이 바로 열립니다.

마이크로데이터는 응답주체·주기별로 6개 파일로 나누어져 있습니다.
모든 파일이 엑셀 행 한도(1,048,576행) 안에 들어가나,
실제 사용은 DB 또는 BI 도구에 적재하는 방식을 전제로 합니다.

## 데이터 갱신 구조

관리자 화면에서 개인 단위 원자료(`micro_*.csv`)를 업로드하면 시스템이 집계합니다.
집계 절차는 `03_집계사양서.md`에 규정되어 있으며, 그 문서만으로 재구현이 가능합니다.

`fact_*` 파일들은 초기 구축에 그대로 사용하는 동시에 **구현 검증용 기준값**입니다.
재집계 결과가 이 파일들과 일치하면 구현이 정확한 것입니다.

동봉된 `05_집계검증.py`가 사양서대로 집계를 수행하고 결과를 대조합니다.
`python 05_집계검증.py` 로 실행하시면 아래와 같이 출력됩니다.

```
  ✔ fact_indicator_wave 행수                1371 (기준 1371)
  ✔ fact_topic_wave 소주제 수                   32 (기준 32)
  ✔ fact_headline 행수                        41 (기준 41)
  ✔ 응답수 불일치 건수                               0 (기준 0)
  ✔ 대표값 최대 오차                              0.0 (기준 0.01 이하)
```

이 스크립트가 사양서의 참조 구현이므로, 로직이 모호할 때 코드를 확인하십시오.

## 식별자 관련

마이크로데이터의 `응답자ID`는 개인 식별자가 아니라 **학교 내 일련번호**이며
(`학교ID × 10000 + 순번`) 주기마다 새로 부여됩니다.
따라서 **주기 간 동일인 연결은 성립하지 않습니다.** 집계에도 사용되지 않습니다.

단 학부모의 `응답자ID`는 자녀의 학생 ID이므로 동일 주기 내에서는 학생–학부모 결합이 가능합니다.

## 현재 확정되지 않은 사항

분류 체계 등 일부 항목이 발주기관 검토 중입니다. 확정 시 데이터를 갱신하여 재전달합니다.
**테이블 구조(컬럼·키·관계)는 변경되지 않으며 행의 수만 달라집니다.**
