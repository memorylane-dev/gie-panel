# 전달 안내

경기교육데이터 시각화 서비스 유지·관리 용역 `[메뉴2-2] 교육데이터 시각화 – 패널 데이터`
(과업지시서 SFR-001) 구축용 데이터입니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `00_전달안내.md` | 이 문서 |
| `01_테이블정의서.xlsx` | 테이블 목록·컬럼 정의·테이블 관계·명명 규칙 |
| `02_집계사양서.md` | **집계 절차 규정.** 관리자 화면에서 원자료를 재집계하므로 필수 |
| `03_집계검증.py` | 집계 참조 구현 겸 검증 도구 |

데이터 파일은 접두어로 성격을 구분합니다.

| 접두어 | 뜻 | 개수 | 담고 있는 것 |
|---|---|---|---|
| **`dim_`** | dimension, **차원** | 8 | 변하지 않는 참조 정보 — 지표 정의, 분류 체계, 코드표 |
| **`fact_`** | fact, **사실** | 5 | 측정 결과 수치 — 시점이 늘면 행이 늘어납니다 |
| **`micro_`** | microdata, **원자료** | 6 | 개인 단위 응답 — 집계의 원본, 갱신 시 업로드 대상 |

## 구축 시 핵심 사항 3가지

**① 그래프에는 `대표값` 컬럼을 사용하십시오.**
지표마다 적절한 통계량이 다릅니다(선택형=환산100점, 이분형=긍정응답률, 금액형=지출자 중앙값).
`대표값`에 이미 계산되어 있으므로 지표 유형별 분기가 필요 없습니다.
**원 `평균` 컬럼으로 그래프를 그리면 4·5·6점 척도가 혼재하여 지표 간 비교가 성립하지 않습니다.**

**② 대분류·소주제 탭은 `dim_category` / `dim_topic`을 읽어 구성하십시오.**
탭 목록을 코드에 고정하지 않고 파일에서 읽어 그리면, 이후 데이터 교체만으로 반영됩니다.

**③ 다계열 그래프는 `dim_cross_respondent`를 확인하십시오.**
복수 응답주체를 한 화면에 표시하는 조합 27개 중 **12개만 성립**합니다.
나머지는 한쪽 주체의 문항이 조사에서 선택되지 않아 단일 계열로 표시해야 합니다.

합산하면 방향이 다른 문항이 상쇄되어 지표가 왜곡됩니다.

## 적용한 정제 규칙

마이크로데이터의 `값` 컬럼에는 아래 처리가 **이미 적용되어 있습니다.** 별도 전처리 없이 집계하십시오.

| 규칙 | 내용 |
|---|---|
| R1 | 다중응답 문항의 미선택 결측을 `0`으로 보정 (적용 행은 `결측보정` 컬럼에 표시) |
| R2 | 코드북 선지 정의 범위를 벗어난 값은 결측 처리 |
| R3 | 연속형(교육비) 음수 값 결측 처리 |
| R4 | 역문항은 자동 역채점하지 않고 `dim_indicator.역문항`에 표시. 소주제 평균에서 제외 |
| R5 | 비교가 성립하지 않는 지표는 `시계열비교가능=N`으로 표시하고 소주제 평균에서 제외 |
| R6 | 지역규모를 학교DB에서 `학교ID`로 결합 |
| R7 | 한 주기에만 분기가 걸린 문항은 응답 기저를 정렬 (해당: 학생 문화활동) |

## 파일 형식

모든 파일은 **압축하지 않은 CSV(UTF-8 BOM)** 이며 컬럼명은 한글입니다.
마이크로데이터는 응답주체·주기별 6개 파일로 나누어져 있고,
모두 엑셀 행 한도(1,048,576행) 안에 들어갑니다.
실제 사용은 DB 또는 BI 도구에 적재하는 방식을 전제로 합니다.

## 데이터 갱신 구조

관리자 화면에서 개인 단위 원자료(`micro_*.csv`)를 업로드하면 시스템이 집계합니다.
집계 절차는 `02_집계사양서.md`에 규정되어 있으며, 그 문서만으로 재구현이 가능합니다.

`fact_*` 파일들은 초기 구축에 그대로 사용하는 동시에 **구현 검증용 기준값**입니다.
동봉된 `03_집계검증.py`가 사양서대로 집계를 수행하고 결과를 대조합니다.

```
$ python 03_집계검증.py

  ✔ fact_indicator_wave 행수                1371 (기준 1371)
  ✔ fact_topic_wave 소주제 수                   32 (기준 32)
  ✔ fact_headline 행수                        41 (기준 41)
  ✔ 응답수 불일치 건수                               0 (기준 0)
  ✔ 대표값 최대 오차                              0.0 (기준 0.01 이하)
```

이 스크립트가 사양서의 참조 구현이므로, 로직이 모호할 때 코드를 확인하십시오.

## 식별자 관련

`응답자ID`는 개인 식별자가 아니라 **학교 내 일련번호**이며(`학교ID × 10000 + 순번`)
주기마다 새로 부여됩니다. 따라서 **주기 간 동일인 연결은 성립하지 않습니다.**
집계에도 사용되지 않습니다.

단 학부모의 `응답자ID`는 자녀의 학생 ID이므로 동일 주기 내에서는 학생–학부모 결합이 가능합니다.
