# 전달 안내

경기교육데이터 시각화 서비스 유지·관리 용역 `[메뉴2-2] 교육데이터 시각화 – 패널 데이터`
(과업지시서 SFR-001) 구축용 데이터입니다.

## 먼저 읽어 주십시오 (순서대로)

| 순서 | 파일 | 내용 |
|---|---|---|
| 1 | `00_README.md` | 데이터 정의서. 화면 영역별 파일 대응, 정제 규칙, 확인 필요 사항 |
| 2 | `01_정의/테이블정의서.xlsx` | 테이블 목록·컬럼 정의·테이블 관계·명명 규칙 |
| 3 | `01_정의/집계사양서.md` | **집계 절차 규정.** 관리자 화면에서 원자료를 재집계하므로 필수 |

## 구축 시 핵심 사항 3가지

**① 그래프에는 `대표값` 컬럼을 사용하십시오.**
지표마다 적절한 통계량이 다릅니다(선택형=환산100점, 이분형=긍정응답률, 금액형=지출자 중앙값).
`대표값`에 이미 계산되어 있으므로 지표 유형별 분기가 필요 없습니다.
**원 `평균` 컬럼으로 그래프를 그리면 4·5·6점 척도가 혼재하여 지표 간 비교가 성립하지 않습니다.**

**② 대분류·소주제 탭은 `dim_category` / `dim_topic`을 읽어 구성하십시오.**
분류 체계가 확정 전이므로 탭 목록이 변경될 수 있습니다.
파일을 읽어 그리도록 구현하면 데이터 교체만으로 반영됩니다.

**③ 다계열 그래프는 `dim_cross_respondent`를 확인하십시오.**
복수 응답주체를 한 화면에 표시하는 조합 27개 중 **12개만 성립**합니다.
나머지 15개는 한쪽 주체의 문항이 조사에서 선택되지 않아 단일 계열로 표시해야 합니다.

## 파일 형식

모든 파일은 **압축하지 않은 CSV(UTF-8 BOM)** 입니다. 별도 도구 없이 바로 열립니다.

마이크로데이터는 응답주체·주기별로 6개 파일로 나누어져 있습니다.
모든 파일이 엑셀 행 한도(1,048,576행) 안에 들어가나,
실제 사용은 DB 또는 BI 도구에 적재하는 방식을 전제로 합니다.

## 데이터 갱신 구조

관리자 화면에서 개인 단위 원자료(`03_마이크로데이터/`)를 업로드하면 시스템이 집계합니다.
집계 절차는 `01_정의/집계사양서.md`에 규정되어 있으며, 그 문서만으로 재구현이 가능합니다.

`02_집계/`의 파일들은 초기 구축에 그대로 사용하는 동시에 **구현 검증용 기준값**입니다.
재집계 결과가 이 파일들과 일치하면 구현이 정확한 것입니다(사양서 8장 참조).

## 식별자 관련

마이크로데이터의 `응답자ID`는 개인 식별자가 아니라 **학교 내 일련번호**이며
(`학교ID × 10000 + 순번`) 주기마다 새로 부여됩니다.
따라서 **주기 간 동일인 연결은 성립하지 않습니다.** 집계에도 사용되지 않습니다.

단 학부모의 `응답자ID`는 자녀의 학생 ID이므로 동일 주기 내에서는 학생–학부모 결합이 가능합니다.

## 현재 확정되지 않은 사항

분류 체계 등 일부 항목이 발주기관 검토 중입니다. 확정 시 데이터를 갱신하여 재전달합니다.
**테이블 구조(컬럼·키·관계)는 변경되지 않으며 행의 수만 달라집니다.**
자세한 내용은 `00_README.md`의 '확인 필요 사항'을 참조하십시오.
