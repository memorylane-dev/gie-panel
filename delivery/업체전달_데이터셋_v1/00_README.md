### 화면에 바로 쓰는 컬럼 — `대표값`

지표마다 적절한 통계량이 다릅니다(선택형은 환산100점, 이분형은 긍정응답률,
금액형은 지출자 중앙값). 그래프를 그릴 때마다 지표 유형을 보고 컬럼을 바꿔 고르지
않도록 **`대표값`** 컬럼에 그 값을 미리 넣어두었습니다. `대표값유형`에 무엇이
들어갔는지 표기되어 있으므로 축 이름·단위 표기에 사용하면 됩니다.

```
그래프 y축      = 대표값
축 이름·단위    = 대표값유형
툴팁 상세       = 평균 / 응답수 / 상위2선지비율 등
```

### 전체와 지역규모를 한 테이블에 담았습니다

`fact_indicator_wave.csv`는 `지역규모` 컬럼으로 두 화면을 모두 커버합니다.

| 화면 | 필터 |
|---|---|
| ⑤-① 연도별 추이 | `지역규모 = '전체'` |
| ⑤-② 지역규모별 비교 | `지역규모 <> '전체'` |

`지역규모='전체'` 행과 지역 행이 함께 들어 있으므로 **합계를 내지 말고 필터로 선택**해야 합니다
(모두 평균값이므로 더하면 의미가 없습니다).

### 상세 통계 컬럼

`응답수 결측수 평균 표준편차 중앙값 백분위25 백분위75 환산100 상위2선지비율 긍정응답률 절사평균 지출자수 지출참여율 지출자평균 지출자중앙값`

지표 유형에 해당하지 않는 컬럼은 비어 있습니다(예: 선택형 지표에 `지출자평균`은 공란).
`대표값`만 쓰면 이를 신경 쓸 필요가 없습니다.

- **환산100** = `(평균 − 척도최소) / (척도최대 − 척도최소) × 100`.
  4점·5점·6점 척도가 섞여 있으므로 **소주제·대분류를 가로지르는 비교에는 반드시 환산100을 사용**하세요.
- **상위2선지비율** = 최상위 2개 선지 응답 비율(%) (5점 척도의 "그렇다+매우 그렇다").
- **긍정응답률** = 이분 문항에서 `긍정코드`(예/참여/해당) 응답 비율(%).
- **절사평균** = 연속형(교육비·사교육비)의 상하위 1% 절사 평균. 이상치 영향이 크므로
  **연속형은 평균보다 중앙값 또는 절사평균 사용을 권장**합니다.

## 5. 반드시 확인이 필요한 사항

### 5.1 연구원 확인 요청 (데이터 이슈)
**2주기 학부모 `PRQ3_2_5`, `PRQ3_2_6`에 `1`(해당) 코드가 없습니다.**
같은 배터리의 `PRQ3_2_1~4`는 0/1이 정상 기록된 반면, `_5`(학교생활)·`_6`(친구관계)는
`0`과 결측만 존재합니다. 결측 비율(각 75.1%, 64.8%)이 1주기 선택률(78.6%, 77.8%)과
근접해 **결측이 사실상 `1`(해당)일 가능성**이 있으나 확정할 수 없어 시계열에서 제외했습니다.
원자료 확인 후 회신 주시면 반영하겠습니다. (`04_품질/qc_exclusions.csv` 참조)

### 5.2 해석 주의 — 헤드라인 1위 지표
`진로·진학 준비`(학부모)가 59.78 → 72.16 (+12.38, +20.7%)로 최대 증가폭이나,
- 해당 도움정도 문항(`PR_CAREER_10~18`)은 **선행 경험 문항에서 '예'로 응답한 학부모만 응답**하는
  조건부 기저이며, 9개 항목 전체가 일제히 +12~13점 이동했습니다.
- 선지 라벨은 양 주기 동일하나(전혀 도움 되지 않는다 ~ 매우 도움 된다), 문항명이
  "진학·진로 만족도"(1주기) → "진로·진학 인식"(2주기)으로 바뀌었습니다.
- 2주기 학부모 표본이 1,482명으로 1주기의 25% 수준입니다.

대표 지표로 전면 배치하기 전 연구원 검토를 권장합니다.
`dim_indicator.csv`의 `응답기저` 컬럼에 조건부 기저 지표가 표시되어 있습니다.

### 5.3 표본 규모 차이
2주기 표본이 1주기 대비 학생 58%, 학부모 25%, 교사 54% 수준입니다.
그래프에 **응답수(N)를 함께 노출**하고, 가중치 미적용 단순 집계임을 표기해 주세요.

### 5.4 학생 핵심역량 점수(C01)
- 인지적 역량(CC)은 양 주기 모두 24문항 기준으로 환산점수 비교 가능합니다.
- 사회적(SC)·자율적(AC) 역량은 **구성 문항 수가 다릅니다**(SC 16→20, AC 12→15문항).
  원점수 총점은 비교 불가로 제외했고, 환산점수(0~100)만 조건부로 제공합니다.
- 2주기는 484명이 역량 점수 결측입니다.
