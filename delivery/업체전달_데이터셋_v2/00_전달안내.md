(과업지시서 SFR-001) 구축용 데이터입니다.

**v2 · 2026-09-24 답변 반영본**입니다. 분류 체계와 헤드라인 대표 선정은 아직 미확정입니다.
`fact_headline`은 검토용 후보 순위이며, 노출 대상의 승인을 의미하지 않습니다.

## 구축 시 핵심 사항 3가지

**① 그래프에는 `대표값` 컬럼을 사용하십시오.**
지표마다 적절한 통계량이 다릅니다(선택형=환산100점, 이분형=긍정응답률, 금액형=지출자 중앙값,
역량=기존 100점 환산점수의 평균, 학교폭력=학생 100명당 발생 건수, 안전교육=학교당 평균 실시 횟수).
`대표값`에 이미 계산되어 있으므로 지표 유형별 분기가 필요 없습니다.
**원 `평균` 컬럼으로 그래프를 그리면 4·5·6점 척도가 혼재하여 지표 간 비교가 성립하지 않습니다.**

**② 대분류·소주제 탭은 `dim_category` / `dim_topic`을 읽어 구성하십시오.**
탭 목록을 코드에 고정하지 않고 파일에서 읽어 그리면, 이후 데이터 교체만으로 반영됩니다.

지표는 반드시 `화면표시`를 함께 적용합니다. `숨김`은 화면에서 제외하고, `단년도`는 해당 연도만
표시하며 증감·시계열 연결을 하지 않습니다. 교사 디지털 활용 역량 4개는 2025 단년도입니다.
학교안전과 역량점수는 지표별 대표값을 사용합니다. 단위·구성이 다른 지표를 하나의 점수로 합치지 않습니다.

**③ 다계열 그래프는 `dim_cross_respondent`를 확인하십시오.**
복수 응답주체를 한 화면에 표시하는 조합 27개 중 **12개만 성립**합니다.
나머지는 한쪽 주체의 문항이 조사에서 선택되지 않아 단일 계열로 표시해야 합니다.

## 적용한 정제 규칙

마이크로데이터의 `값`은 정제된 원척도 응답입니다. 역채점은 소주제 집계 단계에서 적용합니다.

| 규칙 | 내용 |
|---|---|
| R1 | 다중응답 문항의 미선택 결측을 `0`으로 보정 (적용 행은 `결측보정` 컬럼에 표시) |
| R2 | 코드북 선지 정의 범위를 벗어난 값은 결측 처리 |
| R3 | 연속형(교육비) 음수 값 결측 처리 |
| R4 | 문항별 값·분포는 원척도 유지. 지정 역문항 3개는 `구인환산100`에서 역채점해 소주제 평균에 포함. `ST_RELATION_02`는 구인 평균에서 제외 |
| R5 | 비교가 성립하지 않으면 `시계열비교가능=N`. 숨김 지표는 소주제에서 제외하고, 교사 디지털 역량은 단년도 소주제 평균만 제공 |
| R6 | 지역규모를 학교DB에서 `학교ID`로 결합 |
| R7 | 학생 문화활동 10개와 학부모 대화 주제 2개는 시계열·헤드라인 제외 및 화면 숨김 |
| R8 | 학교 중복 응답은 문항별 비결측값이 일치할 때만 통합. 충돌값은 결측 처리 |
| R9 | 역량은 기존 환산점수 3개만 사용. 0점 포함 평균이며 결측값은 대체하지 않음 |

별도 조사 가중치는 없습니다. 응답수(N)를 병기하며, 학교 지표의 N은 학교 수입니다.
학교폭력의 분모는 **해당 문항 값과 학생 수가 모두 유효한 같은 학교 집합**입니다.
발생 건수 합계 / 같은 학교 학생 수 합계 × 100으로 계산하며 피해 학생 비율이 아닙니다.
2주기 학교 자료 110행은 104개교이며 5개교에 중복 응답이 있습니다. 충돌값의 정정은 추가 확인 대상입니다.
교육비 공란의 의미, 사교육 문항 0 코드의 의미, 코드북 라벨 정정은 확인 중입니다.

## 파일 형식

데이터 파일은 **압축하지 않은 CSV(UTF-8 BOM)** 이며 컬럼명은 한글입니다.
마이크로데이터는 응답주체·주기별 8개 파일로 나누어져 있고,
모두 엑셀 행 한도(1,048,576행) 안에 들어갑니다.
실제 사용은 DB 또는 BI 도구에 적재하는 방식을 전제로 합니다.

## 데이터 갱신 구조

관리자 화면에서 개인·학교 단위 원자료(`micro_*.csv`)를 업로드하면 시스템이 집계합니다.
집계 절차는 `02_집계사양서.md`에 규정되어 있으며, 그 문서만으로 재구현이 가능합니다.

`fact_*` 파일들은 초기 구축에 그대로 사용하는 동시에 **구현 검증용 기준값**입니다.
동봉된 `03_집계검증.py`가 사양서대로 집계를 수행하고 결과를 대조합니다.

```
$ python 03_집계검증.py
```

현재 산출물 규모는 지표 집계 1461행, 소주제 32개, 헤드라인 후보 40행입니다.
검증 스크립트는 키·결측·수치·분포·소주제 평균·후보 순위를 재계산해 비교하며 불일치 시 실패합니다.

이 스크립트가 사양서의 참조 구현이므로, 로직이 모호할 때 코드를 확인하십시오.

## 식별자 관련

`응답자ID`는 개인 식별자가 아니라 **학교 내 일련번호**이며(`학교ID × 10000 + 순번`)
주기마다 새로 부여됩니다. 따라서 **주기 간 동일인 연결은 성립하지 않습니다.**
집계에도 사용되지 않습니다.

단 학부모의 `응답자ID`는 자녀의 학생 ID이므로 동일 주기 내에서는 학생–학부모 결합이 가능합니다.
학교 설문의 `응답자ID`는 `학교ID`와 같습니다. 학교 설문은 학교 단위로 한 번만 집계합니다.
