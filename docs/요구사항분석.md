### 2.2 핵심 설계 제약

과업지시서가 명시한 두 가지 설계 원칙이 데이터 구조를 결정했습니다.

1. **대분류는 응답 주체가 아닌 주제 기준으로 구성**
   → 학생·학부모·교사 지표가 하나의 소주제 아래 공존해야 함.
   → 지표 마스터를 `대분류 → 소주제 → 응답주체 → 지표` 4단 구조로 설계.

2. **단일 시점 결과에 그치지 않고 조사 누적에 따라 연도별 추이 확인**
   → 주기별 변수명이 완전히 다르므로(1주기 `Q28` ↔ 2주기 `STQ32`) 지표 ID 기반의
     주기 독립 스키마가 필요. → `indicator_id`를 안정 키로 두고 원변수명은 속성으로 격하.

3. **관리자 UI에서 연구원이 연도별 데이터 갱신 수행 (매핑 구조 변경은 제외)**
   → 신규 주기 추가가 매핑 재작업 없이 행 추가만으로 끝나야 함.
   → 마이크로데이터를 long 포맷으로 두고 집계를 파생시키는 구조 채택.

## 4. 데이터 정제 요구사항 도출

분석 과정에서 확인된, 반드시 처리해야 할 사항입니다.

### 4.1 척도 이질성 — 공통 비교축 필요
4점·5점·6점 척도와 이분·연속형이 혼재합니다. ⑤-② 지역규모별 비교와 ④ 헤드라인 카드는
서로 다른 소주제를 한 화면에서 비교하므로 공통 축이 필수입니다.
→ **환산100** = `(평균 − 척도최소) / (척도최대 − 척도최소) × 100` 을 전 지표에 부여.

### 4.2 복합 배터리의 하위척도 분리
코드북 문항 라벨에 하위척도가 명시된 배터리를 단순 합산하면 반대 방향 문항이 상쇄됩니다.

> **실제 사례**: 학습동기 8문항을 합산하면 27.8 → 31.5로 완만한 상승으로 보이나,
> 하위척도를 분리하면 **외재적 동기 19.1 → 24.9 (+30.4%)** 단독 급등이고
> 내재적 동기는 36.6 → 38.1 (+4.3%)에 그칩니다. 정책적 함의가 정반대입니다.

→ 학습동기(외재적/내재적), 학습전략(정교화/조직화), 자기주도학습(주도성·창의성/자기이해),
   수업(태도·참여/교사 진행/수업 중 평가), 교사효능감·사기를 소주제 단위로 분리.

### 4.3 결측 코딩 불일치
1주기 학부모 다중응답 문항 `Q8_2_1~7`은 `0` 코드 없이 `1`/결측만 존재합니다.
그대로 집계하면 선택률이 항상 100%가 됩니다. → 미선택 결측을 `0`으로 보정, 보정 이력 기록.

### 4.4 역문항
역문항 3개(`ST_RELATION_02`, `PR_RELATION_02`, `PR_RELATION_05`)를 그대로 평균에 넣으면
소주제 점수가 왜곡됩니다. → 자동 역채점하지 않고 표시만 하여 소주제 평균에서 제외.
(역채점 여부는 연구원 판단 사항)

### 4.5 이상치 — 연속형
교육비·사교육비 5개 지표는 2주기 코드북에 이상치 주의가 명시되어 있습니다.
→ 음수 결측 처리 + 중앙값·사분위·상하위 1% 절사평균 병기.

### 4.6 표본 규모 비대칭
2주기 표본이 1주기 대비 학생 58%, 학부모 25%, 교사 54% 수준입니다.
가중치 정보가 없으므로 단순 집계이며, → **모든 그래프에 응답수(N) 병기 필요**.

## 5. 확인 필요 사항 (연구원 회신 요청)

### 5.1 데이터 이슈 — 2주기 학부모 대화주제 코딩
2주기 `PRQ3_2_5`(학교생활), `PRQ3_2_6`(친구관계)에 **`1`(해당) 코드가 존재하지 않습니다.**
같은 배터리의 `PRQ3_2_1~4`는 0/1이 정상 기록되어 있습니다.

| 변수 | 0 | 1 | 결측 | 결측률 | 1주기 대응 선택률 |
|---|---|---|---|---|---|
| `PRQ3_2_5` | 369 | **0** | 1,113 | 75.1% | 78.6% |
| `PRQ3_2_6` | 521 | **0** | 961 | 64.8% | 77.8% |

결측률이 1주기 선택률과 근접하여 **결측이 사실상 `1`(해당)일 가능성**이 있으나 확정할 수
없어 시계열에서 제외했습니다. 원자료 확인 후 회신 주시면 반영하겠습니다.

### 5.2 해석 주의 — 헤드라인 1위 지표
`진로·진학 준비`(학부모) 59.78 → 72.16 (**+12.38, +20.7%**)로 최대 증가폭입니다. 다만:

- 도움정도 문항(`PR_CAREER_10~18`)은 **선행 경험 문항에서 '예'로 응답한 학부모만 응답**하는 조건부 기저
- 9개 항목 **전체가 일제히 +12~13점** 이동 (특정 항목이 아닌 전면적 이동)
- 선지 라벨은 양 주기 동일(`전혀 도움 되지 않는다` ~ `매우 도움 된다`)하나, 문항명이
  "진학·진로 만족도"(1주기) → "진로·진학 인식"(2주기)으로 변경
- 2주기 학부모 표본이 1주기의 25% 수준

→ 대표 지표로 전면 배치하기 전 연구원 검토 권장.
