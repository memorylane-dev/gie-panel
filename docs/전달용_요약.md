# 변수 검토 결과 요약 (구두·메일 전달용)

경기학교교육실태조사 1주기(2021)–2주기(2025) 연계 작업 중 확인된 사항입니다.
연구원이 '사용'으로 표시한 223개 문항을 원자료와 대조한 결과입니다.

---

## 1. 연계 불가 — 10건

'사용'으로 표시됐지만 두 주기를 비교할 수 없는 항목입니다.

**교육비·사교육비 5건 (학부모) — 자체 해결했습니다.**
1주기는 지출이 없으면 0으로 적었고 2주기는 빈칸으로 둬서, 그대로 계산하면
예체능 사교육비가 6.3만원 → 29.5만원(+368%)처럼 보였습니다.

설문지 원본을 대조해 보니 **양 주기 문항 형식이 동일**합니다
("각 항목 당 지출하는 교육비는 월 평균 얼마입니까" + "(   ) 만 원" 기입란,
미지출 시 0 기입 지시는 양쪽 다 없음). 응답자 행동 차이가 아니라
입력·코딩 단계의 처리 차이입니다.

그래서 **지출한 사람만의 평균**으로 기준을 맞췄습니다. 이 방식은 가정이 필요 없습니다.

| 항목 | 1주기 지출자 평균 | 2주기 | 지출자 비율 |
|---|---|---|---|
| 주요교과 | 57.9만원 | 80.2만원 | 81.7% → 84.3% |
| 예체능 | 25.4만원 | 29.5만원 | 24.8% → 38.0% |

주요교과의 지출자 비율이 81.7% 대 84.3%로 거의 같다는 점이
2주기 빈칸이 미지출을 뜻한다는 해석을 뒷받침합니다.
→ **확인은 받되 작업은 진행 가능합니다.**

**자녀와의 대화 주제 2건 (학부모)**
2주기 `PRQ3_2_5`(학교생활), `PRQ3_2_6`(친구관계)에 '해당' 응답이 한 건도 없습니다.

2주기 코드북은 이 문항의 값을 **0=해당없음, 1=해당** 두 가지로 정의하고 있고,
같은 묶음의 `PRQ3_2_1~4`는 실제로 0과 1이 모두 기록되어 결측이 없습니다.
반면 `_5`, `_6`은 0과 빈칸만 있고 둘의 합이 정확히 전체 응답자 수(1,482명)와 일치합니다.
1주기에 학교생활은 78.6%로 **가장 많이 선택된 대화 주제**였는데
2주기에 0%라는 것은 성립하기 어렵습니다.
→ 빈칸이 '해당'일 가능성이 높으나 단정할 수 없어 **원자료 확인 부탁드립니다.**

**나머지 3건** — 연구원이 이미 비교 불가(③·④)로 판정한 항목이라 추가 확인은 불필요합니다.
학생 수업 문항 1건, 교사효능감 문항 1건, 2주기에서 삭제된 교사 연수 '자기계발' 1건입니다.

## 2. 추가 검토 — 12건

'사용' 표시는 없지만 과업지시서가 요구하는 화면을 채우려면 필요해 보이는 항목입니다.

**학교안전 대분류가 통째로 비어 있습니다 (학교용 설문 3건)**
과업지시서 표4의 9개 대분류 중 '학교안전'에 해당하는 데이터가 없습니다.
그런데 학교용 설문을 직접 열어보니 **양 주기에 다 있고 항목이 그대로 대응합니다.**
- 학교폭력 발생 빈도: 1주기 `Q8_1~8` ↔ 2주기 `SCQ10_1~8` (8개 항목 순서까지 동일)
- 안전교육 실시 횟수: 1주기 `Q12_1~8` ↔ 2주기 `SCQ14_1~8` (항목명 완전 동일)

변수매칭 대상이 학생·학부모·교사 3종이라 학교용이 검토되지 않았을 뿐입니다.
→ **학교용 설문까지 매칭을 확대할지 결정이 필요합니다.**

**학생 핵심역량 6건**
표4의 첫 번째 대분류 '학생성장'의 유일한 내용인데, 변수매칭표의 참고 시트에 있어
'사용' 표시가 없습니다. 제외하면 그 탭이 통째로 빕니다.
→ **포함 여부 결정이 필요합니다.**

**차별경험 (학생)**
표4에 '체벌·차별 경험'이 소분류로 명시돼 있는데, 양 주기에 다 있으나 미선택입니다.
쓰려면 코딩 방향을 뒤집어야 합니다(1주기 1=예 / 2주기 1=없다).

**나머지** — 가구소득(척도가 금액에서 3점 척도로 바뀜), 교사 디지털역량(2주기 신규),
학생 성별(1주기에 없음) 등입니다.

## 3. 주의 필요 — 11건

사용은 하되 해석에 유의가 필요한 항목입니다.

**표본이 크게 줄었습니다**
학생 8,884 → 5,173명(58%), 교사 5,189 → 2,800명(54%),
**학부모 5,948 → 1,482명(25%)** 입니다. 가중치 변수가 없어 단순 집계입니다.
→ 그래프에 응답자 수를 함께 표시해야 합니다.

**헤드라인 1위 지표에 함정이 있습니다**
학부모 '진로·진학 준비'가 +20.7%로 증가폭 1위인데,
앞 문항에서 '경험 있다'고 답한 사람만 응답하는 구조입니다.
9개 항목이 일제히 같은 폭으로 움직였고 문항명도 '만족도'에서 '인식'으로 바뀌었습니다.
→ 대표 지표로 내세우기 전에 검토가 필요합니다.

**공개수업 만족도도 같은 구조입니다**
참여자만 답하는데 빈칸 비율이 1주기 81%, 2주기 59%입니다.
참여율 자체가 변한 것이므로 만족도만 비교하면 오해를 부릅니다.

**코드북 오류 1건**
1주기 `Q9_친구_4`, `Q9_친구_5`의 변수 설명이 '가족_4)', '가족_5)'로 잘못 적혀 있습니다.
데이터는 정상이고 매칭도 올바르게 되어 있습니다.
→ 코드북 정정만 필요합니다.

**응답 학교 수가 파일마다 다릅니다**
학교DB는 179 → 177교인데 실제 응답은 학생 139교, 학부모 125교, 교사 161교, 학교 104교입니다.
지역규모로 나누면 읍면지역 표본이 특히 작아집니다.

## 확인 요청 정리

| | 내용 |
|---|---|
| 1 | 2주기 교육비 빈칸이 미지출이 맞는지 (지출자 기준 통계로 우회 처리함) |
| 2 | 2주기 `PRQ3_2_5`·`PRQ3_2_6`에 '해당' 응답이 없는 사유 |
| 3 | 학교용 설문까지 변수매칭을 확대할지 (학교안전 대분류 충족) |
| 4 | 학생 핵심역량 점수를 포함할지 (학생성장 대분류 충족) |

| 6 | 별도 가중치 보유 여부 |

1번은 지출자 기준 통계로 우회했으므로 확인만 받으면 되고, 2번은 회신이 오면 바로 반영됩니다.
3·4번은 화면 구성이 바뀌므로 업체 설계 착수 전에 정해야 합니다.
