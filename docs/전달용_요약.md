# 경기학교교육실태조사 1·2주기 연계 검토 결과

연구원이 '사용'으로 표시한 223개 문항을 원자료(SPSS)·코드북·설문지와 대조한 결과입니다.

| 구분 | 건수 |
|---|---|
| 그대로 비교 가능 | 175 |
| 비교 시 주의 필요 | 43 |
| 비교 불가 | 5 |
| **'사용' 표시 합계** | **223** |

---

## 1. 결측 처리 방식이 달라진 것으로 추정되는 변수

주기 간 응답자 행동이 아니라 **입력·코딩 단계의 처리 방식**이 달라진 것으로 보이는 경우입니다.

### 1-1. 교육비·사교육비 5개 (학부모 `Q3_1`, `Q3_2_1~4` → `PRQ2_1~5`)

| | 1주기 | 2주기 |
|---|---|---|
| 결측률 | 0% | 48~83% |
| 0값 비율 | 75~92% | 0% |

⇒ **미지출을 1주기는 `0`으로 기입하던 것이 2주기에는 `공란`으로 바뀐 것으로 보입니다.**

설문지 문항은 양 주기가 동일합니다("각 항목 당 지출하는 교육비는 월 평균 얼마입니까"
+ `( ) 만 원` 기입란, 미지출 시 0 기입 지시는 양쪽 모두 없음).
주요교과의 지출자 비율이 1주기 81.7%, 2주기 84.3%로 근접해 이 해석과 부합합니다.

**처리** — 가정이 필요 없는 *지출자 기준* 통계를 병행 산출했습니다.
주요교과 57.9 → 80.2만원(+38.5%), 중앙값 50 → 60만원.
보정 전 전체 평균으로는 +70%로 나오던 값입니다.

### 1-2. 자녀와 대화 주제 7개 (학부모 `Q8_2_1~7` → `PRQ3_2_1~7`)

| | 1주기 | 2주기 |
|---|---|---|
| 정의된 코드 | `{1}` (예) | `{0, 1}` (해당없음 / 해당) |
| 미선택 표기 | 공란 | `0` |
| 결측률 | 21~68% | 0% (1~4번) / 65~75% (5~6번) |

⇒ **미선택을 1주기는 `공란`으로 두던 것이 2주기에는 `0`으로 명시하도록 바뀐 것으로 보입니다.**

**처리** — 1~4번(공부·용돈·건강·진로)은 1주기 공란을 `0`으로 채워 기저를 맞췄습니다.
5번(학교생활)·6번(친구관계)은 2주기에 `1`이 한 건도 없어 별도 확인이 필요합니다(→ 2-2).

### 1-3. 학생 문화활동 10개 (`Q9_가족_1~5`, `Q9_친구_1~5` → `STQ8_1_*`, `STQ8_2_*`)

| | 1주기 | 2주기 |
|---|---|---|
| 결측률 | 0% | 20.4% (1,055명) |
| 응답 대상 | 전원 | 사교육 참여자만 |

⇒ **2주기에 사교육 참여 여부(`STQ7`) 문항의 분기가 문화활동까지 걸린 것으로 보입니다.**
결측자 1,055명 집합이 `STQ7=2`('아니오') 응답자 1,055명과 **정확히 일치**합니다.
문화활동은 사교육과 무관한 문항이므로 설문 설정 오류로 추정됩니다.

**영향** — 1주기 기준 사교육 미참여자의 문화활동 점수는 15.73으로 참여자(21.66)보다
5.94점 낮습니다. 이들이 빠지면 2주기 평균이 구조적으로 상승합니다.

```
전체 기준      20.50 → 24.05  (+3.55)   ← 헤드라인 9위였음
기저 정렬 후   21.66 → 24.05  (+2.39)   ← 증가폭 약 1/3 축소
```

**처리** — 1주기도 사교육 참여자로 한정해 기저를 맞췄습니다.

## 2. 비교 요청 목록에 있지만 비교가 불가능한 변수 — 5건

### 2-1. 연구원이 이미 비교 불가로 판정한 3건 (추가 확인 불필요)

| 지표 | 응답주체 | 문항 | 사유 |
|---|---|---|---|
| `ST_CLASS_09` | 학생 | 학습 과정 점검·개선 기회 제공 | 측정 내용 변경 (판정 ③) |
| `TR_EFFICACY_08` | 교사 | 나는 책임감이 높다 | 측정 내용 변경 (판정 ③) |
| `TR_TRAIN_03` | 교사 | 교사 연수 — 자기계발 | 2주기 문항 삭제 (판정 ④) |

### 2-2. 확인이 필요한 2건

| 지표 | 문항 | 현황 |
|---|---|---|
| `PR_TALK_06` | 대화 주제 — 학교생활 | 2주기 `1`(해당) 0건, `0`과 공란만 |
| `PR_TALK_07` | 대화 주제 — 친구관계 | 2주기 `1`(해당) 0건, `0`과 공란만 |

2주기 코드북은 이 문항을 `0=해당없음, 1=해당`으로 정의하고 있고, 같은 묶음의
`PRQ3_2_1~4`는 0과 1이 모두 기록되어 결측이 없습니다. 5·6번만 `0`과 공란뿐이며
둘의 합이 정확히 전체 응답자 수(1,482명)와 일치합니다.
1주기에 학교생활은 **78.6%로 가장 많이 선택된 대화 주제**였으므로 2주기 0%는
성립하기 어렵습니다. 공란이 '해당'일 가능성이 높으나 단정할 수 없습니다.

## 3. 비교 요청 목록에 없지만 비교가 가능한 변수 — 약 24건

### 3-1. 학생 핵심역량 환산점수 3건 — 표4 대분류 '학생성장'

`CC_conversion`, `SC_conversion`, `AC_conversion` (0~100점)

과업지시서 표4의 9개 대분류 중 첫 번째인 '학생성장'의 유일한 소분류입니다.
연구원이 산출한 점수인데 변수매칭표의 **참고 시트**에 있어 '사용' 표시가 없습니다.
제외하면 해당 대분류가 공란이 됩니다.

인지적 역량은 양 주기 모두 24문항 기준이라 그대로 비교 가능하고,
사회적·자율적 역량은 구성 문항이 늘어(16→20, 12→15) 환산점수만 조건부로 비교 가능합니다.
원점수 총점은 만점이 달라져(80→100, 48→60) 비교 불가입니다.

### 3-2. 학교안전 16건 — 표4 대분류 '학교안전' 전체

| 소분류 | 1주기 | 2주기 | 대응 |
|---|---|---|---|
| 학교폭력 발생 빈도 | `Q8_1~8` | `SCQ10_1~8` | 8개 항목 순서까지 동일 |
| 안전교육 실시 횟수 | `Q12_1~8` | `SCQ14_1~8` | 8개 항목명 완전 동일 |

**데이터가 없는 것이 아니라 매칭이 안 된 것입니다.** 연구원 변수매칭 대상이
학생·학부모·교사 3종이라 학교용 설문이 검토되지 않았습니다.
2주기에 학교폭력 3개 항목(자해·도박·약물)과 안전교육 1개 항목(회복적 생활교육)이
추가되었으나 기존 8개는 그대로입니다.

단, 학교폭력은 발생 **건수**이므로 학교 규모 보정이 필요합니다
(학생 1,000명당 발생률로 환산).

### 3-3. 차별 경험 4건 — 표4 소분류 '체벌·차별 경험'

`Q17_1~5` → `STQ29_1~4`. 양 주기에 모두 존재하나 '사용' 미표시입니다.
**코딩 방향이 반대**(1주기 `1=예/2=아니오`, 2주기 `1=없다/2=있다`)이므로
역코딩이 선행되어야 하며, 항목 수가 5→4로 줄어 공통 4개만 대응 가능합니다.

## 4. 비교 요청 목록에 있지만 비교 시 주의가 필요한 변수 — 43건

### 4-1. 조건부 응답 — 응답자가 선행 문항으로 걸러지는 문항

| 문항 | 1주기 결측 | 2주기 결측 | 비고 |
|---|---|---|---|

진로·진학 준비가 +20.7%로 증가폭 1위인데, 9개 항목이 일제히 +12~13점 이동했고
문항명도 '진학·진로 만족도'에서 '진로·진학 인식'으로 바뀌었습니다.
응답 집단 자체가 다를 가능성이 있어 대표 지표 배치 전 검토가 필요합니다.

공개수업 만족도는 결측률 차이가 곧 참여율 변화이므로,
만족도만 비교하면 더 중요한 정보를 놓칩니다.

### 4-2. 표본 규모 차이 (전 지표 공통)

| 응답주체 | 1주기 | 2주기 | 비율 |

## 5. 값 처리(역채점)가 선행되어야 하는 변수 — 4건

문항-나머지총점 상관으로 판별했습니다. 음수이면 같은 척도 내 다른 문항과 방향이 반대입니다.

| 지표 | 문항 | 상관 (1주기/2주기) | 처리 |
|---|---|---|---|
| `ST_RELATION_06` | 선생님들은 나에게 무관심하다 | −0.326 / −0.135 | 역채점 |
| `PR_RELATION_05` | 선생님들은 내 아이에게 관심이 부족하다 | −0.380 / −0.449 | 역채점 |
| `PR_RELATION_02` | 친구들이 내 아이에게 상처를 준 적이 있다 | −0.102 / −0.194 | 역채점 |
| `ST_RELATION_02` | 친구들이 나에게 상처를 준 적이 있다 | **+0.011 / +0.068** | 척도 부적합 |

`ST_RELATION_02`는 의미상 부정 문항이나 상관이 0에 가깝습니다.
방향이 반대인 것이 아니라 척도와 무관하게 움직이므로 역채점 대상이 아닙니다.
현재는 4건 모두 하위척도 평균에서 제외하고 표기만 하고 있습니다.
