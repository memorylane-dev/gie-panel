# 시각화 업체 인터페이스 협의안

연구원 회신을 기다리는 동안 병렬로 진행할 수 있는 항목이다.

## 왜 병렬 진행이 가능한가

현재 대기 중인 결정은 모두 **어떤 지표가 포함되는가**(테이블의 행)에 관한 것이고,
인터페이스 협의는 **테이블이 어떤 모양인가**(열·키·형식)에 관한 것이다.
행이 늘거나 줄어도 스키마는 바뀌지 않는다.

| 대기 중인 결정 | 스키마 영향 |
|---|---|
| 학생 핵심역량 6개 포함 여부 | `dim_indicator`에 6행 증감. 열 구조 불변 |
| 학교안전(학교용 설문) 추가 | `dim_category`에 1행, 지표 16행 증가. 열 구조 불변 |
| 역문항 역채점 | 값만 변경. 구조 불변 |
| 교육비 결측 처리 | `시계열비교가능` 플래그만 변경 |
| 초·중·고 확장 | `학교급` 열이 이미 존재 |
| 3주기 추가 | `조사연도` 값 추가. 이미 대응 |

유일한 예외는 **학교용 설문 추가 시 응답 단위가 개인이 아닌 학교가 된다**는 점이다.
마이크로데이터의 `응답자ID`에 `SCHID`가 들어가게 되므로, 이 경우의 표기 규칙만
미리 정해두면 된다.

## 협의 안건

### 1. 전달 형식 — 우선 결정 필요

현재 산출물은 UTF-8 BOM CSV이다.

| 선택지 | 내용 | 추가 산출물 |
|---|---|---|
| (a) CSV 직접 연결 | BIX5가 파일을 직접 읽음 | 없음 |
| (b) DB 적재 | 테이블로 적재 후 연결 | 테이블 정의서, DDL, 키 정의 |

과업 최종산출물 목록에 *테이블 목록·테이블 정의서·데이터 코드목록*이 포함되어 있으므로
(b)를 전제로 보이나, BIX5 v21의 연결 방식 확인이 필요하다.

### 2. 관리자 UI의 갱신 입력 단위 — 가장 중요

과업지시서는 *"연구원 담당자가 연도별 데이터 갱신을 수행할 수 있는 인터페이스"* 를 요구한다.
무엇을 업로드하는지에 따라 **집계 로직의 소유권**이 갈린다.

| 선택지 | 업로드 대상 | 집계 수행 주체 |
|---|---|---|
| (a) 마이크로데이터 | 개인 단위 long 데이터 | **업체 시스템**이 집계 로직 구현 |
| (b) 집계 테이블 | 이미 계산된 집계값 | 연구원 측이 정제 스크립트 실행 후 업로드 |

(b)가 단순하나 연구원이 매번 스크립트를 돌려야 한다.
(a)는 업체가 환산100·하위척도 평균·헤드라인 순위 산출을 시스템에 이식해야 한다.

### 3. 스키마 세부

| 항목 | 현재 상태 | 확인할 것 |
|---|---|---|
| 컬럼명 | 한글 (`지표명`, `응답수`, `환산100`) | BIX5·DB에서 한글 컬럼명 허용 여부. 불가 시 영문 병기 필요 |
| 인코딩 | UTF-8 BOM | 적재 도구의 요구 인코딩 |
| 기본키 | `indicator_id` + `조사연도` (+`지역규모코드`) | 복합키 사용 가능 여부 |
| 결측 표현 | 빈칸 | NULL / 특정 코드(-9 등) 중 무엇을 쓸지 |
| 소수점 | 평균 4자리, 환산100 2자리 | 표시 자리수 및 반올림 규칙 |
| 파일 교체 | 전체 교체 | 증분 갱신 필요 여부 |

### 4. 화면 동작 규칙

데이터 구조와 무관하게 업체 설계에 필요한 항목이다.

- **헤드라인 카드**: 상위 몇 개를 표시할지(과업지시서는 "n개"로만 기재),
  순위 기준을 증감폭으로 할지 증감률로 할지, 동점 처리 방식
- **다계열 그래프**: 응답주체 간 비교 27개 조합 중 12개만 성립한다.
  나머지 15개는 한쪽 주체 문항이 미선택되어 단일 계열로 표시된다.
  성립 불가 조합 목록을 전달할 예정
- **최소 표본 기준**: 지역규모로 분할 시 읍면지역 셀이 작아진다.
  표본 n 미만은 값을 숨길지, 표시하되 경고를 붙일지
- **조건부 응답 지표의 분모 표기**: 진로·진학 준비, 공개수업 만족도 등은
  응답 대상자가 제한되므로 분모를 화면에 어떻게 밝힐지

## 권고 진행 순서

1. **1·2번을 먼저 확정한다.** 업체의 개발 착수 조건이며 리드타임이 가장 길다.
2. 3번은 1번 결정 후 자동으로 좁혀진다.
3. 4번은 연구원 회신과 무관하므로 지금 논의 가능하다.
   단 헤드라인 순위 기준은 대표 지표 선정(진로·진학 준비 건)과 맞물리므로
   연구원 검토 결과를 반영할 여지를 남겨둔다.
