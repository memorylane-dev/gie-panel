## 학교 자료 처리에서 확인된 추가 사항

2주기 학교 파일은 110행이지만 고유 학교는 104개이며, 5개교에서 중복 응답이 발견됐습니다.
공통 16문항 중 **학교·문항 조합 40건**은 중복 응답의 값이 서로 다릅니다.

원자료의 행 순서로 대표 응답을 고르거나 합산하지 않습니다. 문항별로 0 이상의 정수인 비결측값이
하나로 일치하면 한 학교 응답으로 통합하고, 여러 값이면 해당 학교·문항만 결측 처리했습니다.
이는 원자료 정정 전의 잠정 정제 규칙입니다. 중복 응답의 원인과 정정본은 추가 확인 대상으로 남깁니다.
`micro_school_2025.csv`의 `결측보정` 열에 통합·충돌 이력이 있습니다.

학생 수는 양 주기 모두 학교DB의 1·2·3학년 남녀 학생 수 6개를 합산해 연결할 수 있습니다.
값이 충돌한 문항의 학교는 발생률 분자와 분모에서 함께 제외합니다.
학교별 발생률의 단순 평균이 아니라 **유효 응답 학교의 건수 합계 / 같은 학교들의 학생 수 합계 × 100**입니다.
학교당 건수 평균으로 대체하는 방식은 사용하지 않았습니다.

## 집계 오류 수정

기존 v1 생성 코드는 소주제 평균을 구할 때 전체 집계와 중소도시·읍면지역 집계를 함께 평균냈습니다.
소주제 평균은 **전체 집계(지역규모코드 0)만** 사용하도록 수정했습니다.
이로 인해 이번 결정과 직접 관련 없는 소주제·헤드라인 값도 일부 변경됐습니다.

예를 들어 진로·진학 준비는 v1의 59.89 → 72.09에서 v2의 **59.78 → 72.16**으로 바뀌었습니다.
이는 기존 검토 문서의 수치와 일치합니다. 역문항을 포함한 관계 소주제는 이번 결정의 효과도 함께 반영됩니다.
