# ID 구조와 매칭 방법

두 주기 자료를 어떻게 이어 붙였는지 정리한 문서다. 결론은 **학교는 이어지고 사람은 이어지지 않는다.**

## 1. 파일에 있는 ID

| ID | 자리수 | 구조 | 들어 있는 파일 |
|---|---|---|---|
| `SCHID` 학교 ID | 4 | 학교 고유번호 (예: `1001`) | 학생·학부모·교사·학교·학교DB 전부 |
| `STUID` 학생 ID | 8 | 학교ID(4) + 학교 내 순번(4) — 예: `10011001` | 학생, 학부모 |
| `TID` 교사 ID | 7 또는 8 | 학교ID(4) + 순번 — **주기별로 자리수가 다름** | 교사 |

변수명은 양 주기 모두 동일하다. 10개 파일 전체를 훑어 다른 이름의 연결 변수가 있는지 확인했으나 없다.

## 2. 주기 간 무엇이 달라졌나

| | 1주기 (2021) | 2주기 (2025) |
|---|---|---|
| 학생 순번 | `1001`~`1067` (학교당 평균 49.6명) | `1001`~`8809` (학교당 평균 37.2명) |
| 교사 ID | 7자리 `SCHID×1000 + 순번(1~78)` | 8자리 `SCHID×10000 + 순번(1001~3800)` |
| 예시 | 교사 `1001001` | 교사 `10011491` |

`STUID // 10000 == SCHID` 는 양 주기 모두 100% 성립한다. 즉 학생 ID는 **개인 식별자가 아니라 학교 내 일련번호**이며, 주기마다 새로 부여된다.

## 3. 검증 결과

### 개인 연결 — 불가

| 대상 | 1주기 | 2주기 | 교집합 | 비율 |
|---|---|---|---|---|
| 학생 `STUID` | 8,884 | 5,173 | 40 | 0.8% |
| 학부모 `STUID` | 5,948 | 1,482 | 3 | 0.2% |
| 교사 `TID` | 5,189 | 2,800 | **0** | 0% |

- 학생 교집합 40명은 **전부 한 학교(`SCHID=1001`)** 에서 나왔다. 그 학교만 2주기에도 `1001`부터 채번해 우연히 충돌한 것이다.
- 진짜 패널이라면 공통 학교 기준 **최대 4,991명**이 겹쳐야 한다.
- 교사는 자리수 체계가 달라 애초에 겹칠 수 없다.
- 근본적으로 2021년 중학생은 2025년에 고등학생이므로, 두 조사 모두 중학교 대상인 이상 동일인 재응답은 성립하지 않는다. **반복 횡단 설계**다.

### 학교 연결 — 가능 (검증됨)

176개교가 양 주기에 공통으로 존재한다. 같은 학교인지 확인하기 위해 잘 바뀌지 않는 속성을 대조했다.

| 검증 항목 | 결과 |
|---|---|
| 설립구분 (공립/사립) | **100% 일치** |
| 지역규모 (중소도시/읍면) | **100% 일치** |
| 남녀공학 구분 | **100% 일치** |
| 학급 수 상관계수 | 0.939 (평균 차이 2.2학급) |

`SCHID`는 주기 간 안정적이다.

### 주기 내 학생–학부모 연결 — 가능

학부모 파일의 `STUID`는 본인 번호가 아니라 **자녀의 학생 ID**다.

| 주기 | 짝지어지는 쌍 | 학부모 대비 |
|---|---|---|
| 1주기 | 5,424쌍 | 91.2% |
| 2주기 | 1,180쌍 | 79.6% |

같은 사건을 학생과 학부모가 각각 보고한 문항(예: 가족 동반 문화활동 횟수)은 평균 비교뿐 아니라 **응답 일치도** 분석이 가능하다. 단 각 주기 내부에서만 성립한다.

## 4. 그래서 어떻게 매칭했나

사람을 잇는 대신 **문항을 이었다.**

1. **문항 연결** — 주기 간 변수명이 다르므로(`Q28` ↔ `STQ32`) 연구원 변수매칭표를 기준으로 문항마다 고정 키 `indicator_id`를 부여했다. 원변수명은 속성으로 격하한다.
2. **번호가 아니라 내용으로** — 문항 삭제로 번호가 밀린 곳이 많다. 예: 교사 연수는 1주기 `3)자기계발`이 삭제되며 이후가 전부 밀렸다(`Q27_4` → `TRQ14_3`). 번호를 신뢰하면 엉뚱한 문항끼리 붙는다.
3. **학교 정보 결합** — 응답자의 `SCHID`로 해당 주기 학교DB를 조회해 지역규모(`YM1_DB0_3`/`YM2_DB0_3`)를 붙였다.
4. **집계 단위** — 개인 연결이 불가하므로 각 주기를 별개 집단으로 두고 평균을 산출한다. 개인의 변화가 아니라 **집단 수준의 변화**다.

## 5. 주의 — 응답 학교 수는 파일마다 다르다

| 파일 | 1주기 | 2주기 |
|---|---|---|
| 학교DB | 179교 | 177교 |
| 학생 응답 | 179교 | **139교** |
| 학부모 응답 | 179교 | **125교** |
| 교사 응답 | 179교 | **161교** |
| 학교 설문 | 179교 | **104교** |

`dim_school.csv`는 학교DB 기준이라 응답이 없는 학교도 포함한다. 지역규모로 분할하면 읍면지역 셀이 특히 작아지므로 최소 표본 기준이 필요하다.
